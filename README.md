# Tamil Cinema Word Cloud Studio — v0.1

Open `index.html` directly in a modern browser.

Phase 1 features:
- Tamil Unicode text input
- word splitting and duplicate removal
- repeat/weight control
- 16:9, square, portrait and story presets
- transparent/dark/gradient backgrounds
- circle, heart, star, diamond and rectangle masks
- typography and layout controls
- deterministic random seed
- PNG export

This version intentionally uses browser Canvas so it remains standalone. A later iteration can add custom PNG/SVG masks, local font loading, better spiral packing, editable per-word weights, richer cinematic effects, presets, and project save/load.
